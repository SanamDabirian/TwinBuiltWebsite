# TwinBuilt Studio website

Static marketing site for TwinBuilt Studio, built with Astro for GitHub Pages at [twinbuiltstudio.net](https://twinbuiltstudio.net).

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Contact and consultation requests use placeholder Google Form URLs in `src/data/forms.ts` until live forms are supplied.
